# iOS 26 本机实时字幕接入说明

适用范围：Turbo IO iOS V1，最低系统版本 iOS 26。build 14 的音源、本机转写和翻译已经过用户真机验证。build 15 增加显示选项与“完成”保存行为，已通过 Actions 编译。build 16 增加设置页交互预览和译文失败提示，Actions 编译及签名安装后的真机验收待完成。

## 处理链路

字幕设置提供三种互斥的音频来源：

| 来源 | 采集与处理 | 眼镜条件 |
| --- | --- | --- |
| 眼镜音频流 | 业务 19 音频包 → Opus 解码 → 16 kHz 单声道 PCM → 所选识别引擎 | 必须连接；可切换“前方 / 四周” |
| iPhone 内置麦克风 | 指定内置输入端口 → AVAudioEngine → 16 kHz 单声道 PCM → 所选识别引擎 | 不需要眼镜 |
| 系统麦克风 | 跟随系统录音输入或指定系统可见端口 → AVAudioEngine → 同上 | 不需要眼镜 |

手机麦克风使用前请求系统录音权限，并在启动后核对实际输入端口。指定端口不可用或系统未切到该端口时直接报错；录音中路由变化、中断或队列积压会停止会话并保存已收到的内容。“系统麦克风”指系统提供给本 App 的录音输入，不包括其他 App 的播放音频。

眼镜作为音源时，沿用实时字幕业务 19 的收音启动、Opus 音频、文字显示、停止及 `direction` 设置。用户已在 build 13 真机验证“前方”模式抑制两侧声源，“四周”可收到侧方声源。手机麦克风作为音源时，若用户开启“同时显示在眼镜”且眼镜已连接并空闲，只走已验证的显示协议 `type 7 → type 8 → type 5 → type 3`；不会发送眼镜收音启动命令。眼镜显示失败或断连时，手机收音和手机字幕继续。

## 本机识别与翻译

选择“Apple 本机识别”后，`SpeechTranscriber` 与 `SpeechAnalyzer` 接收上述 PCM。首次使用需准备所选语言的模型；启动前再次检查设备、语言和模型状态。当前字幕设置使用明确的中文或英文语言，Apple 本机识别不使用自动语言检测，也不需要 API Key。模型由 iOS 管理，其支持情况以真机查询结果为准。

“本地翻译”独立于识别服务，可与本机或云端识别组合。固定中文识别语言的目标为英文；固定英文识别语言的目标为中文。设置页通过系统 `translationTask` 请求下载语言包；运行时只使用已安装语言包，对**最终字幕**逐句翻译。原文与译文分别归档，译文以独立 `translation` 记录保存。暂定识别结果不触发翻译。

用户在 build 14 真机确认：iPhone 内置麦克风和眼镜麦克风均可收音，Apple 本机转写和本地翻译均可工作。该结果说明基础链路已跑通；它不代表 build 15 的显示时序已经验收。

## 字幕显示偏好（build 15）

显示偏好作用于**手机实时字幕和眼镜实时字幕**，不筛掉已归档的原文或译文。识别语言为中文时，中文是原文、英文是译文；识别语言为英文时则相反。

| 显示模式 | 实时画面 |
| --- | --- |
| 只看中文 | 只显示中文。若中文来自翻译，等待最终译文完成后上屏，不先闪出英文原文。 |
| 只看英文 | 只显示英文。若英文来自翻译，等待最终译文完成后上屏，不先闪出中文原文。 |
| 中英混合 | 同时显示原文与译文，可选“原文在上”或“译文在上”。 |

混合模式的顺序由字幕设置选择。停留方式可选“直到下一句”（默认）、3 秒、5 秒或 10 秒。只看识别原文所属语言时，下一句的暂定识别结果可立即上屏。只看译文所属语言或使用中英混合时，已有的完整译文或双语显示不会被下一句的暂定原文覆盖；“直到下一句”会等下一句所选内容就绪后替换。定时停留从所选内容就绪时起算；到期后手机清空实时显示。眼镜显示协议不接受空串，因此向眼镜发送空白字符；实际清屏效果仍需真机确认。

只看某个语言时，若识别语言与该语言不同，需开启本地翻译并准备对应语言包。关闭翻译时，设置页会将显示模式切回识别语言；保存仍依赖译文的模式会提示用户修正。

build 16 起，若只看译文所属语言，而某一句翻译失败或没有返回可用内容，实时画面改为所选语言的“本句翻译暂不可用”或 “Translation unavailable”，避免上一句内容一直留在画面上被误认作当前语音。该提示只用于手机与眼镜的实时显示，不写入字幕或翻译归档；原文仍按正常流程保存。中英混合模式在译文失败时回退显示该句的最终原文。

## 设置页交互预览（build 16）

“字幕设置 → 显示预览”提供模拟手机字幕画面。修改识别语言、翻译开关、显示模式、混合顺序或停留时间时，预览直接使用当前草稿更新，便于保存前检查效果。预览默认停在 8.6 秒，开启翻译时首句译文已就绪，并按当前模式显示；点击“从头播放”可观看完整过程。可选择“正常翻译”或“第二句翻译失败”，使用播放／暂停和 0–29 秒进度拖动查看任意阶段；未开启翻译时失败情景不可选。

示例时间线包括第一位说话者的长句暂定识别与最终识别、约 2.4 秒的译文生成间隔、第二位说话者开始时的暂定识别、下一句译文或失败提示，以及“直到下一句”和 3／5／10 秒停留的差异。预览只使用内置的中英文示例文字，不启动麦克风、识别服务、云端连接或系统翻译会话。它演示手机上的显示规则；眼镜上的字体与排版仍以真机为准。

## 设置与诊断

字幕设置保存音源、指定系统端口 UID、翻译开关、眼镜显示开关、服务、语言、收音方向及显示偏好。build 15 起，点击右上角“完成”会保存当前修改，保存失败时留在设置页并显示原因；原有“保存字幕设置”按钮仍可使用。全天智记运行时的应用策略仍需用户选择后才完成保存。端口 UID 只留在本机设置中；“分享脱敏诊断”只输出音源类别、实际端口**类型**、模型与语言包状态码、包数、PCM 字节数、缺口数、有限的控制协议事件和延迟计数。不得把设备名、端口 UID、音频、字幕正文、密钥或原始序号放进脱敏诊断。

排障时先看实时页的“实际输入”名称是否符合预期，再分享脱敏诊断。若识别没有开始，依次检查录音权限／输入路由、识别模型或云服务连接、本地翻译语言包状态。眼镜音源还需核对业务 19 启动回执、方向指令和音频包增长。

## Actions 构建与真机检查

`.github/workflows/ios-rollback-build.yml` 使用 macOS 26、Xcode 26.6 和 iOS 26 SDK 构建设备目标并关闭代码签名。历史构建 [build 15 Actions](https://github.com/kanhao100/Turbo-IO/actions/runs/36356866211) 已成功产出 `TurboIO-iOS26-v0.4.0-build15-unsigned-ipa`，其中 IPA 文件为 `TurboIO-iOS26-v0.4.0-build15-unsigned.ipa`，SHA-256 为 `c305363c97e05272c1c20c952263a7be3aa6d87aa95f1a7969d27c2de0a398b0`；产物校验通过。build 16 的 Actions 编译和 IPA 产出尚待确认。IPA 需要用户自行签名后安装，build 16 的真机功能验收也仍待完成。

建议在已签名安装后逐项检查：

1. Apple 本机识别分别准备中文、英文模型；确认无 Key 也能开始，并观察暂定与最终字幕。
2. 准备中文→英文和英文→中文翻译语言包；分别核对只看中文、只看英文和混合模式，确认历史导出仍同时含原文与译文。
3. 在无眼镜时分别用 iPhone 内置麦克风、系统当前麦克风开始，核对实际输入路由及音频包数增长。
4. 连接眼镜并启用“同时显示在眼镜”；确认眼镜只显示手机麦克风的字幕，眼镜断连时手机字幕继续。
5. 切到眼镜音频流，用侧方声源对比“前方 / 四周”，检查切换指令后音频包数继续增长。
6. 测试录音权限拒绝、指定端口拔出、来电中断、模型或语言包尚未下载时的提示与保存行为；分享脱敏诊断检查无正文和设备名。
7. 修改显示模式、混合顺序和停留时间，仅点击“完成”后重新打开设置页，确认三项均已保存；保存失败时确认页面不会关闭。
8. 连续说两句话，确认原文单语模式可立即显示下一句暂定字幕，而译文单语与双语模式会保留上一句完整显示直到下一句所选内容就绪；分别检查“直到下一句”和 3／5／10 秒停留。对比手机与眼镜的替换和清屏效果。
9. 在设置页拖动预览进度，并用“第二句翻译失败”情景确认单语译文失败提示与混合模式原文回退；检查该提示只出现在实时显示，不进入历史或导出内容。
