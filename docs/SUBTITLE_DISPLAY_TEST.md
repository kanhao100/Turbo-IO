# 先验证眼镜字幕显示

目标是先让手机产生的流式文字稳定显示在眼镜上，再接入实际声音和 ASR。本阶段基于 `acc71e8` 回滚版本；不恢复此前四家 ASR/AI 对话重构。四家转写适配器仍保存在 Git 历史，后续确认音频协议和显示效果后再接回。

普通录音“App 开始后立即提示已保存、无法停止”的问题已单独记在 [设备问题记录](DEVICE_ISSUES.md)，本阶段不修改其开始/停止协议。

## 手机上的操作

测试版版本为 **0.2.1 (5)**。Actions 成功后下载 `TurboIO-subtitle-display-unsigned-ipa`，解压得到 IPA，按原流程用自己的 Apple ID 签名安装。构建产物附 SHA-256；不能把旧版同名 App 当成本次测试结果。

1. 在“设备”页连接并认证眼镜。先在眼镜端退出录音、提词器、语音和其他显示任务，回到首页。
2. 打开底部独立的 **字幕** 页，确认眼镜空闲，点击 **打开字幕显示**。此操作会暂停 App 的 AI 语音待命；无需唤醒词、普通录音、ASR Key 或 DeepSeek Key。
3. 收到眼镜的本轮设置回执后，App 发送“字幕测试 · XXXX”。手机显示相同的预期文字，请在镜片上核对本轮校验码。
4. 点击 **播放流式字幕**。同一会话每秒更新一帧：中文逐步增长、换行、替换成下一句、英文逐步增长。观察覆盖/叠加、缺字和闪烁；没有接入声音识别，不把合成文字当作真实字幕。
5. 实际看到相同文字后，可点击 **我在眼镜上看到了同样的文字**，记录人工验收；设置回执和 SDK 提交成功都不会自动把这一项标为通过。
6. 点击 **停止并退出字幕**，在镜片上确认已回首页，再点击 **眼镜已退出，结束本轮测试**。退出不确定时可以重试退出请求，或先在眼镜手动退出再确认。无需卸载、解绑或清理 App 数据。

出现问题时，分享本页“诊断记录”。记录包含版本、阶段、帧数、回包类型/错误码和人工确认结果，不含密钥、音频、设备标识或私人转写文本。最好同时说明镜片实际显示了什么。

## 实际协议路径

使用原生字幕 **business 19**，沿用仓库 `official-addon/SubtitleHUDCore.m`、`ProtocolContext.m` 和鸿蒙 `BusinessCommands.ts` 已有的显示协议：

| 阶段 | 消息 | 边界 |
| --- | --- | --- |
| 打开显示 | type 7，新的 32 位 SID，`scope=temporary`、`force=false`，原有五行/居中/原文配置 | 只提交临时显示设置，不发字幕录音启动 type 1 |
| 设置回应 | type 8，同一设备和 SID，整数 `code=1/2` | 每次都需新回执，10 秒超时即请求退出；不借用旧 ACK |
| 更新文字 | type 5，`mode=3`、`status=0`、`content.source_transcript` | 同句更新语义；最多 384 UTF-8 bytes，不验证最终历史或翻译模式 |
| 退出 | type 3，同 SID，`reason_code=10`、空 `text` | 发送成功或收到 type 3 都不等于物理退出，保留人工确认 |

临时显示配置来自已有实测范围，不能保证每一版眼镜固件都兼容。因此新回执是必要条件，镜片可见仍需佩戴者确认。模式 3 的流式显示方式先通过合成文字测试；正式 ASR 的中间稿、定稿和历史显示需要后续单独设计。

接收桥补齐 business 19，发送桥只允许这三个明确的显示包，并单独关联 SDK 异步发送失败。若收到意外字幕音频 type 4，只上报事件并结束显示测试，不把音频交给解码、文件或云端。显示期间暂停语音控制、普通录音、提词器及其他显示命令；未确认退出前不自动恢复它们。

每轮最多 60 秒，文字提交最多 80 帧，间隔至少 0.5 秒（演示默认 1 秒）。离开页面或进入后台请求退出；退出等待 8 秒后显示“尚未确认”，没有无限重试。断连后不向新设备发退出、不自动重新打开字幕；用户确认原眼镜退出后才能再次建立新会话。

## 验证范围

```sh
node --test scripts/check-source.test.mjs
node scripts/check-source.mjs
swift test --package-path rayneo-protocol
node scripts/test-subtitle-display.mjs
```

协议测试检查显示包白名单、配置与文字格式、ACK 的设备/SID/类型、布尔错误码、超时、限频、异步发送失败、意外音频、断连与旧会话隔离。模拟器测试实际 `SubtitleDisplayRuntime` 的打开 → ACK → 流式文字 → 停止 → 人工退出过程，以及独立页面在无设备时无法开启。测试使用合成文字和假传输；设备版另做 iPhoneOS 编译，产物版本在打包时校验。

实机待验项：标题是否出现、校验码是否一致、文字是否更新/换行、是否闪烁、退出是否有效。**这些项目必须根据本次签名 iPhone 和眼镜的实际结果填写，CI 不预填通过。**

## 显示通过后的实时字幕链路

先单独确认眼镜字幕音频的开始/停止、包格式和采样参数，再转换为所选 ASR 所需的 PCM；将供应商的中间识别和定稿变成显示帧，通过已验证的字幕会话更新镜片。显示功能不依赖 AI 回答，也不需要把普通录音文件当作实时音频输入。当前阶段不实现这条音频/ASR 链路。
