# iOS V1 本机存储空间管理

适用范围：Turbo IO iOS V1，最低系统版本 iOS 26。build 19 的存储页可从“工具 → 存储空间”或“偏好设置 → 存储空间与清理”打开。本文说明扫描口径、清理范围与真机验收方法。build 19 已通过 GitHub Actions 的 iPhoneOS 设备编译；真机清理验收仍待安装后执行。

## 页面使用

页面打开时扫描本 App 的已知文件目录，显示总字节数、可清理副本与缓存、按用途分类的占用及文件数。只有有文件的类别展开显示，零占用类别合并提示；右上角可重新扫描。字幕会话按占用大小或创建时间排序，可按名称搜索；每条显示本机实际文件占用，其中录音部分单独列出。点“查看与导出”进入原有会话详情。已校验录音分别显示本机音频和笔记的实际文件字节，并可进入归档详情；旧版录音、眼镜接收文件及便携副本保留到原有查看、导出或恢复页面的入口。

对于已结束的字幕会话，有两种独立操作：

| 操作 | 结果 |
| --- | --- |
| 只清录音 | 删除该会话的 `audio-####.wav`，保留 `session.json`、`captions.jsonl`、译文与会话列表。以后无法回听，也无法重新导出已删的音频。 |
| 删除 | 删除该会话在本 App 的整个本机目录，包括字幕与录音。 |

两者均先显示标题、预计占用和删除范围，再由用户确认。进行中的字幕会话及尚未完成保存的会话不可清理；点击删除时会先停止回听。清理只针对手机 App 沙盒，不向眼镜发送删除指令。会话删除与音频清理后重新扫描占用；读不到或结构异常的目录不会被当作普通会话删除。若逐个音频片段删除时发生磁盘或权限错误，可能只清理了其中一部分；界面会报错并要求重新扫描核对剩余占用。旧会话的 `audioPurgedAt` 字段可选，无需迁移。

已校验录音归档可逐条点击“删除本机归档”。确认框列出扫描时实际存在的音频及全部笔记字节，并明确告知将移除本机录音、笔记和归档登记；不会向眼镜发送删除指令。已经单独生成的便携 ZIP 副本仍由“ZIP 导出副本”页面管理。清理前可先从归档详情导出。存储页仅对音频与所有登记笔记均存在且属于普通文件的条目显示删除操作；归档正执行其他事务、该条录音正在手动转写或已有校验异常时不显示。确认后会重新核对条目的归档元数据及修订列表；若期间新增笔记或记录变化，要求重新扫描并确认。归档接口在提交删除前复核音频与笔记的字节校验，并用持久化日志处理删除；若写入日志后中断，下一次恢复会继续完成该条删除。删除后刷新占用，已打开的归档详情自动退出，避免继续操作已删除记录。

归档删除先写入事务日志，再发布不含该条记录的新清单，最后按登记的文件名逐个校验并移除文件。如果文件在清理期间发生改动，或目录同步失败，归档保留剩余文件和日志并停止其他归档操作。此时应保留原件，待文件或设备状态恢复后重新打开归档，不要直接在“文件”App 中删改归档内部文件。

“可清理副本与缓存”管理两类文件：

- 字幕和全天智记分享缓存：仅清理已生成超过一小时、名称和类型符合本 App 导出格式的文件。近期副本可能仍在系统分享流程中，因此保留；原始会话不变。
- 已移入 ZIP 导出暂存箱的便携副本：新生成的副本带有 App 写入的归属标记；旧完整副本可用快照清单识别。清理前核对副本内快照的 `audio/`、`notes/`、清单所列文件及 ZIP 名称和类型；未写出清单的失败暂存快照仅在带归属标记且内部目录为空时可清理。旧版未标记的失败临时包及未知、额外或结构异常的文件原位保留。删除时逐个移除已识别文件，再尝试移除空目录，不递归删除目录；若期间出现新文件，清理会中止并保留剩余目录。原始归档不变。“移入暂存箱”本身不释放空间，只有永久清理后才会释放。

## 统计口径

扫描只遍历本 App 明确拥有的目录，不跟随符号链接。分类包括：已校验录音归档、旧版导入录音、实时字幕会话、全天智记文字、本地书库、对话时间轴、眼镜录音接收箱、便携导出副本及暂存箱、录音恢复副本、提词稿发送箱、手动识别诊断、旧版全天智记诊断、字幕和智记分享缓存，以及导入录音实验和归档导入的临时文件。相同目录或嵌套目录不会重复计入总量。逐条显示的字幕、录音与书籍占用来自实际文件；单条字幕录音只计算符合 `audio-####.wav` 命名且确为普通文件的片段。已校验录音逐条数字只包括其音频和已登记笔记；共享清单、恢复日志等归入类别总量，不能按单条归属。归档登记的文件如已缺失，会按零字节计入并显示扫描提示，删除入口不会显示。

页面显示的是文件逻辑字节数，不等于 iOS“设置 → iPhone 储存空间”中的 App 总占用。文件系统开销、系统管理的 Apple 语音识别模型与翻译语言包、Keychain 和部分系统缓存不在可归因的 App 文件统计内。临时目录可能由 iOS 清理；正在使用或无法确定归属的临时文件只显示，不提供一键删除。

已校验录音通过归档自身的逐条删除接口处理；存储页不会直接按文件路径删除归档内部文件。眼镜接收箱、旧版导入录音及其他未建立完整删除流程的个人资料仍只读，可到对应功能查看和导出。删除本机归档不会清理最初导入时位于其他位置的来源文件，也不会清理已生成的独立 ZIP 副本。

## 实现位置

- `apps/RayNeoCompanion/Sources/LocalStorageInventory.swift`：已知目录扫描、分类、可清理量计算与操作路由。
- `apps/RayNeoCompanion/Sources/StorageSpaceView.swift`：概览、分类、搜索排序、操作说明与确认。
- `rayneo-archive/Sources/RayNeoArchive/ArchiveStore.swift` 与 `apps/RayNeoCompanion/Sources/LocalArchiveController.swift`：已校验录音的逐条删除与归档状态更新。
- `apps/RayNeoCompanion/Sources/SubtitleArchiveStore.swift`：已结束字幕会话的音频清理；会话整体删除沿用原方法。
- `apps/RayNeoCompanion/Sources/PortableExportCopies.swift` 和 `LocalArchiveController.swift`：已识别 ZIP 暂存副本的永久清理。

## 真机检查

1. 录制一段同时保存字幕和音频的会话。打开存储页，确认会话总量和“录音”字节数大于零，排序与名称搜索可用；在详情中先导出需要保留的资料。
2. 点击“只清录音”并确认。再次扫描后录音字节数应为零，会话和字幕仍可打开，详情说明录音已清理；手机回听和包含音频的重新导出不应声称音频仍存在。
3. 再录制一段并尝试在会话运行或保存期间从存储页清理，确认操作被阻止。结束后删除整条会话，确认列表与占用变化，且眼镜上的文件未被操作。
4. 生成字幕或智记分享文件，确认一小时内的副本不会被清理；超过一小时的副本可清理，原会话仍可重新导出。
5. 生成便携 ZIP 副本，移到暂存箱。仅移动时占用不应减少；在存储页或“ZIP 导出副本”页永久清理后，占用应减少，原归档可继续查看。结构异常或未知文件应保留并提示。
6. 对照 iOS 系统的 App 储存数据，确认页面文案没有把系统模型或文件系统开销误算成可清理缓存。
7. 在已校验录音中选择含笔记的条目，核对录音与笔记的实测占用；导出所需内容后删除本机归档，确认归档列表和占用下降、原详情不再可操作，眼镜文件与独立 ZIP 副本仍在。另在手动 ASR 转写同一条录音时确认删除入口不可用；若在确认期间新增笔记，旧确认须失效并要求重新扫描。
