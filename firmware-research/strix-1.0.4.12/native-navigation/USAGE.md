# TNV1：从配套手机源码到导航验收

> **仅适合能理解日志、版本锁定、签名和变砖风险的开发者。** 无救砖条件、重要主力设备、电量不足或版本不符时，不要刷。禁止边驾驶、骑行或过马路边操作。

## 准备：先装手机，不刷眼镜

1. 按 [BUILD.md](BUILD.md) 构建并自行签名。宿主只适配雷鸟 AI iOS **1.0.5（201）**；眼镜基线 Strix OS **1.0.4.12**。Android/HarmonyOS 尚未配套此 TNV1 升级入口，不能拿普通客户端替代。
2. 提前备份 App 数据和自己可用的旧包；不要上传个人日志/Key/证书。配对使用官方流程；如果原来绑定另一台手机，先在那台官方 App 解绑、系统蓝牙忽略，再进入蓝灯配对。已正常连接则无需重置。
3. 在官方设置**关闭固件自动更新**；开启再关闭一次可确保该账号的设置已保存。门禁必须读到明确 false，否则拒绝授权；不要改代码跳过。
4. 结束录音、提词、导航、语音，眼镜放在手机旁并保持手机亮屏、电量充足（建议至少50%）。安装/升级期间不要强退、断蓝牙、断电、拔充电或切换 App 版本。
5. 打开「TurboIO → 诊断 → TNV1 导航固件 · 默认锁定」，等待 **内置TNV1候选校验通过**。这时未开放下载、未授权刷写。若没有入口，是普通构建或旧包；若哈希不符，立即停止。

## 下载与只读复核：这一步也不等于允许刷写

1. 在实验页点 **开启15分钟只下载验收**。本机来源临时提供唯一固定 ZIP，OTA发送仍由门禁阻止。
2. 回官方固件页重新检查，按官方页面下载。官方可能显示同样的版本号1.0.4.12；**版本号不能区分本实验与原厂，必须核对实验页哈希**。
3. 下载/解压后回实验页点 **核对官方解压目录**。必须完整匹配14项负载和清单；如下载失败、旧缓存、目录不符或未知错误，停止。不要反复点安装，也不要自行清空所有 App 数据。

## 一次授权与官方安装（高风险、自行决定）

1. 再确认无任务、电量充足、蓝牙稳定及自动更新关闭。先在官方固件页重新读取版本；**两分钟内**回实验页点 **允许一次 TNV1 实验试刷**，阅读警告并输入 `TNV1`。
2. 仅在显示 **授权：1**、匹配文件已冻结后，返回官方页手动点“开始安装/立即更新”。授权并不替你点击；过期就停下重新核对，不能跳过门禁。
3. 保持供电、连接和 App 状态，等待官方传输与眼镜安装完成。**传输成功/发送ACK不等于眼镜启动成功**；一旦已经安装，不要强杀 App、重新授权或重发。
4. 等眼镜正常重启并重新连接，核对原七个菜单、第八 Turbo Display、第九导航。确认升级已彻底完成后，重启一次手机 App 清除进程内的一次性OTA会话；**不要在升级过程中重启**。
5. 出现异常、失去蓝牙/无法启动时，不要连续重刷。保留本地状态/日志，先分析；没有已验证的“一键救砖”。原厂基线仅用于研究，不保证能降级或恢复。

本实验包的本机升级查询默认只报告无更新，只在显式15分钟窗口提供 TNV1。**它不应作为日常官方升级客户端**；需要正常官方升级时，请先结束所有实验任务，换回兼容的普通构建/原版，先核对未来固件兼容性。升级原厂固件可能移除扩展菜单。

## 导航：选原生通道，不选旧字幕/提词器

1. 手机打开「TurboIO → 资料库 → 步行/骑行/驾车导航」，阅读高德隐私说明，填写自己的 **高德 iOS Key**（绑定自己的实际 Bundle ID），授予所需定位权限。
2. 先用模拟：选模式，选起点和终点（搜索或地图选点），点规划，再点开始模拟。手机必须已有转向和距离。
3. 在 **眼镜原生导航 · TNV1** 区点 **开启眼镜原生导航**。眼镜留在首页即可自动进入；不要同时开启旧字幕、提词器、录音或 Turbo Display。
4. 核对箭头、距离、路名和右侧路线示意图；默认60秒没有有效更新息屏，也可选导航常亮。强退、手机被系统终止、定位权限撤销均不保证连续导航。
5. 点 **停止并退出眼镜导航** 结束镜片显示，或眼镜实体返回；点 **结束导航** 停止手机路线。真实导航后台使用定位服务；模拟退后台只有短时额度，不能拿模拟自动停止当成真实导航立即断开。

## Turbo Display 仅用于传图测试

在眼镜第八项进入 Turbo Display，再在手机「诊断 → Turbo Display · 传图测试」读取会话/SID，选择本地图片并发送。图片在手机处理成512×128灰度，实际镜片绿色单色；大图不会按原始像素传输。iCloud图片需先下载到手机，文件终态与眼镜回执都到达才算一轮提交。首次全帧可能慢；局部更新可能有中间画面，**不承诺无撕裂/视频刷新**。不要用本测试工具冒充应用级导航。

## 常见问题

| 现象 | 检查 |
| --- | --- |
| 看不到 TNV1 入口 | 确认构建标志、`--experimental-ota TNV1`、最新源码和实际安装版本；普通 R3 包不含它。 |
| “未授权/版本读数过期” | 关闭官方自动更新，刷新真实设备版本，2分钟内确认；不要绕过门禁。 |
| 下载/目录校验失败 | 只用本次Release精确ZIP；旧R3、原厂包、重新压缩包都会拒绝。 |
| 刷完导航发送被拒绝 | 先确认眼镜升级/重启/连接均完成，再重启手机App一次；不在OTA途中操作。 |
| 眼镜显示“请从手机开始导航” | 只是手动打开了导航页；手机需开始路线并点击“开启眼镜原生导航”。 |
| 只在手机有导航 | 核对实际固件有第九菜单、配对连接和TNV1专用按钮；不要用旧字幕入口。 |
| 模拟锁屏后停止 | 系统短时后台额度限制；真实导航需定位授权，不承诺强退恢复。 |
| Key/证书/签名问题 | 本仓库没有作者配置；用自己的服务与开发者证书，不上传到issue。 |

报告问题时只提供宿主/固件版本、步骤、脱敏错误码和本地校验结果；移除个人设备标识、地址/路线、聊天及凭据。
