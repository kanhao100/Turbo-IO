## 一个测试工具，一个导航应用

| 功能 | 用途与边界 |
| --- | --- |
| 第八项 Turbo Display / TDP1 | **Test：开发调试工具**。512×128 L8 灰度画布，手机传整图或局部矩形，支持读取 SID。不是视频投屏、日常应用或任意尺寸图片引擎。 |
| 第九项导航 / TNV1 | **独立导航应用页面**。540×180 LVGL 布局；眼镜本地绘制箭头、距离、道路文字、最多32点路线示意图。手机只传最大328字节语义快照，不再连续传整幅导航位图。 |
| 手机主动启动 | 已绑定、首页空闲且未折叠时，手机 START 可进入导航；不需要手动进眼镜菜单。不抢占录音、语音等原厂任务。 |
| 生命周期 | 默认60秒无有效导航更新息屏，按钮唤醒、可选常亮、STOP/退出及断连保护；心跳不伪造新导航数据。 |
| 后台导航 | 对应手机源码含后台修复：真实导航按授权使用定位后台；模拟限系统短时额度（最多25秒），不承诺无限后台模拟。 |

“独立应用”指固件 Launcher 内拥有独立菜单和生命周期的页面，不是 APK/HAP、动态安装平台或沙盒。路线示意图**不是高德地图底图/街道地图/路口实景**；请以手机和道路实际指示为准。

## 为什么只改 application

所需菜单、LVGL 和接收路由均在 `nuttx_ap.bin`：在其中追加受限模块并修改必要入口，避免同时改动蓝牙核、音频核、安装器和资源分区，缩小审查与排错范围。

- **14项负载中，仅 `nuttx_ap.bin` 改变；另13项逐字节保持原厂。**
- AP 增长21,164字节；原有区域实际改变106字节；新增模块21,153字节。
- `OtaFileInfo.json` 只更新 AP 的 Size/MD5，其余记录保持原样；外层 ZIP 的 MD5/SHA-256 重新计算。
- **内容只改 AP ≠ 完整 OTA 只写 AP ≠ 不会变砖。** 官方安装仍可能写入未变化的其他负载；AP 不是故障隔离的手机 App。
