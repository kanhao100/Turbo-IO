## A. 官方 App 提供原厂更新时

这是优先路径，但它取决于官方是否向你的设备提供兼容更新；不保证可选择历史版本或同版本重装。

1. **先确认上一轮升级已彻底结束。** 如果眼镜尚在更新或状态不明，不退出 App、不解除保护、不反复重试。眼镜自然回首页后，完成配套插件的只读回查和结果保护收尾；Android GUARD-07 见[安装教程第 4 节](https://github.com/Turbo1123/Turbo-IO/blob/main/android-addon/docs/INSTALL_AND_FLASH.md#4-必做自然重启--只读回查--释放保护)。
2. 导出需要保留的录音、稿件和手机配置。**安装官方手机 App、解绑或恢复手机设置，本身都不会把眼镜固件恢复为原厂。**
3. 使用没有实验 OTA 来源拦截的官方 RayNeo App。研究修改版可能把更新查询指向本机实验源，不要仅凭界面长得像官方就确认来源。切换官方 App 前先备份；Android 重签名研究 APK 与官方签名可能冲突，卸载会删除沙盒数据，不要盲目覆盖/卸载。
4. 正常连接眼镜，结束全天智记、录音、对话、提词、导航、音乐和阅读。电量至少 50%，并遵守官方更严格的要求；手机保持充足电量和稳定连接。
5. 在官方 App 的眼镜设置／关于本机／软件版本中检查更新。**只有官方确实提供适配本机的原厂更新才继续。** 此路径使用官方返回的下载，不上传本页 ZIP，也不伪造版本号。
6. 按官方页面下载并更新一次。传输和安装期间不要关闭蓝牙、强退、切换宿主、断电或主动重启；手机上传完成不等于眼镜安装完成。
7. 等眼镜自然启动、重新连接，检查官方版本信息、原厂菜单、抬头显示、亮度和常用功能。若目标确为去除扩展，新增 Turbo 菜单/运行时应不再存在；只看相同版本号不能证明恢复成功。

官方提示“已是最新”时，到这里停止。不能承诺本路径会强制覆盖已修改但版本号未变的 AP。

## B. 同版本重刷：归档可供核对，公开恢复入口尚未交付

当前公开 Android **GUARD-07** 只接受 **TAP1-TEST-01** 的固定 ZIP/AP/清单；iOS 各实验门禁也各自固定候选。直接选择本原厂归档会被拒绝，这是预期保护，**不是把文件改名即可解决**。

要让用户真正执行同版本原厂覆盖，还需要单独实现并验收“原厂恢复”候选配置：

- 明确设备型号与当前版本兼容范围，固定本归档 ZIP 和全部 15 项文件摘要，而非放开任意包；
- 完整原厂清单不变，核对全部 Size/MD5/BurnMode/BurnAddr/BurnPath；下载信息使用 ZIP 自身校验值，不能拿 AP MD5 代替；
- 只下载 → 回读官方解压目录 15/15 → 当前电量/空闲/连接预检 → 单次明确授权 → 官方 Mode 2 流程 → 自然重启 → 只读回查和保护收尾；
- 把“显示TEST/Turbo 菜单存在”等实验版验收项改为适合原厂恢复的核验，不能要求恢复后仍显示自定义标记；
- 对错包、旧缓存、超时、断连和同版本请求失败保持禁止发送；完成真实恢复验收后才能提供普通用户操作按钮。

**本次发布的是归档、离线校验工具和恢复条件说明，没有提供上述恢复专用 APK/IPA。** 不应从这些开发要求推导出“下载本 ZIP 就能刷回”；不会指导用户绕过现有门禁或手工往设备地址写数据。需要恢复但没有官方更新时，先联系官方支持或等待经过验证的专用恢复入口。

## 下载后离线核对

把 Release 中 ZIP、`stock-audit.json` 与 `SHA256SUMS.txt` 放到同一目录：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

然后使用仓库内脚本逐项复核（不解压落盘，不连接设备）：

```sh
python3 firmware-research/strix-1.0.4.12/stock/archive.py verify /absolute/path/StrixOS-1.0.4.12-STOCK-PAYLOADS-REPACK.zip
```

输出 `verifiedStockMembers: 15` 仅表示与已归档的原厂基线一致，不代表厂商签名验证、当前机型兼容或可刷写授权。具备同一原厂解压基线的开发者可使用 `pack --directory <基线目录> --out <不存在的新目录>` 重新归档；不同 Python/zlib 版本可能产生不同 ZIP 压缩字节，不能拿重打包结果直接替代固定候选。

**风险最后再强调：** 有原厂包不代表一定能回滚；原厂包恢复、实验包升级都可能因为掉电、中断、型号/版本不匹配或底层故障而失败。若 OTA 通道已不可用，应走官方检修，而非反复刷写。
