# 第三方与公开范围

原创扩展遵循根目录 PolyForm Noncommercial 1.0.0；原厂应用/固件和第三方 SDK 权利不转移。

- `MusicAPI.m` 部分兼容逻辑参考 Beans Music（MIT），保留原注释，见 [MIT 全文](../music/Beans-MIT-LICENSE.txt)。打包脚本把该许可证一并放进本机产物。
- 高德 SDK 自行按其条款下载与配置，不在本目录分发 SDK 包或 Key。
- 微信读书书架/统计参考 Tencent/WeChatReading 的公开接口；网页全文参考项目 `finlater/weread.koplugin` 为 AGPL 独立 KOReader 插件。本目录**未分发网页正文适配或 Cookie 实现**，仅有原创建架、封面处理与用户提供 TXT/EPUB 的解析传输。
- 可选本地翻译组件沿用 [独立第三方清单](../local-translation/THIRD_PARTY.md)，模型权重和许可证需使用者自行准备。
- `TurboIOArt` 为项目 UI 生成素材，不含私人屏幕、账号或设备数据。宣传图标注为效果示意，不代表原厂官方背书或所有视觉细节已实现。
